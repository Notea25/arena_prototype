# Arena — кликабельный прототип

Копия сайта `arena-front` в обычных HTML/CSS/JS-файлах, на демо-данных. Нужна, чтобы менять дизайн и сразу смотреть, как он работает: без бэкенда, без npm, без сборки.

## Как открыть

Двойной клик по `index.html`. Слева — все экраны по ролям (гость, фан, клуб, агент, рекламодатель) и модалки. Сверху — ширина: телефон 375, планшет 768, десктоп 1440. Любой экран можно открыть и отдельно: `pages/<экран>.html`.

Внутри экрана работают:
- переходы по меню и ссылкам между экранами;
- вход и регистрация по шагам: email → роль → пароль → код → готово. Код — любые 6 цифр;
- выпадашки: язык, уведомления, меню профиля; бургер-меню на телефоне;
- вкладки и фильтры: задания, лидерборд, профиль, кабинет клуба.

Если элемент ведёт на экран, которого нет в прототипе, внизу появится подсказка.

Состояние можно открыть прямо по ссылке: `pages/home.html#open=signup-role`.

## Где что менять

| Что поменять | Где |
|---|---|
| Цвет, шрифт, отступ, радиус — **сразу везде** | `css/tokens.css` — переменные `--color-…`, `--font-…` и т. д. |
| Вид одного компонента (кнопка, карточка задания, шапка) | `css/components/<Компонент>.css` |
| Текст или разметка конкретного экрана | `pages/<экран>.html` |
| Модалки входа и регистрации, выпадашки | `js/overlays.js` (разметка внутри обратных кавычек) |
| Общие стили, сброс, шрифты | `css/global.css` |

Как найти нужный файл: откройте экран в Chrome, правый клик → «Просмотреть код». Класс вида `TaskCard__title` означает компонент `TaskCard`, то есть файл `css/components/TaskCard.css`, правило `.TaskCard__title`.

Вкладки и шаги лежат внизу файла экрана в блоках `<template data-proto-variant="…">`. Если меняете текст на экране с вкладками, поправьте его и в этих блоках.

Не все цвета удалось привязать к токенам: у компонентов бывают свои оттенки и `rgba(...)`. Список лежит в `tools/report.md`, такие цвета правятся прямо в файле компонента.

## Что это за данные

Задания, новости, клубы и лидерборд записаны с dev-стенда, тексты заменены на демонстрационные. Профиль фана, прогресс по заданиям, кабинет клуба и агента — выдуманные. Видео грузятся из хранилища dev, для них нужен интернет. Остальное лежит в `assets/`.

## Как пересобрать с актуального фронта

Нужно, когда фронт заметно поменялся. **Пересборка перезаписывает `pages/`, `css/`, `js/`, `assets/`**: сначала сохраните свои правки (git-ветка) или перенесите их во фронт.

```sh
cd tools
npm install
npx playwright install chromium          # один раз
node mock-api.mjs &                      # демо-API на :4100
./prepare-front.sh                       # копия arena-front, собранная на демо-API
(cd .work/front && PORT=3100 node node_modules/next/dist/bin/next start -p 3100 &)
node capture.mjs                         # снимает экраны по tools/scenarios.mjs
node build.mjs                           # собирает прототип, отчёт — tools/report.md
node verify.mjs                          # сверяет с живым фронтом, отчёт — tools/report-verify.md
```

Список экранов, вкладок и модалок задаётся в `tools/scenarios.mjs`, демо-тексты — в `tools/mock/content.mjs`, данные залогиненных ролей — в `tools/mock/handlers.mjs`. Чтобы дописать недостающие ответы с dev-стенда: `RECORD_UPSTREAM=https://api.dev.bcsarena.io node mock-api.mjs`.
